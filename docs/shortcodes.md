# 短代码使用教程

正文是 Markdown 渲染的，但「一段视频」「一个音频」「一个下载卡片」「一张会动的实况图」没法用纯 Markdown 表达，于是有了短代码。本文列出目前支持的全部短代码、参数顺序和常见坑。

> 适用位置：**文章正文、独立页面、文档正文**（这三处走 Markdown 渲染）。
> 动态正文与评论**不支持**短代码——它们是纯文本 + 表情渲染，写了只会原样显示。动态发实况图请用配图右下角的「实况」按钮。

## 一、速查表

| 短代码 | 用途 | 语法 |
| --- | --- | --- |
| `@[video]` | 视频播放器 | `@[video](视频地址 "标题")` |
| `@[audio]` | 音频播放器 | `@[audio](音频地址 "标题")` |
| `@[file]` | 附件下载卡片 | `@[file](文件地址 "文件名" "体积")` |
| `@[live]` | 实况图（封面 + 短视频） | `@[live](视频地址 "封面图地址" "说明")` |
| `![]( )` | 普通图片 | `![说明](图片地址)` |
| `[emoji: ]` | 行内表情图 | `[emoji:表情图地址]` |
| `@昵称` | 提及用户 | 手打 `@昵称`，保存时自动转链接 |
| `#话题#` | 话题标签 | 手打 `#话题名#`，保存时自动转链接 |

## 二、通用规则（先看这四条，能省掉八成问题）

1. **地址只认两种**：`http://`、`https://` 开头的完整地址，或以 `/` 开头的站内地址。`javascript:`、`data:`、相对路径（`images/a.jpg`）一律不渲染，会原样显示源码。
2. **地址里不能有空格和右括号 `)`**：短代码靠右括号收尾，地址中一旦出现这两个字符就会被截断。上传到站内附件库的地址天然满足这一点。
3. **引号参数是可选的**，但顺序固定、不能跳位。标题/说明里**不要写英文双引号 `"`**，会把参数截断；需要用引号时改用中文引号「」。
4. **不要写 HTML**：正文是 `html: false` 渲染，`<video>`、`<img>` 会被当成普通文本转义显示。所有富媒体只能通过下面的短代码。

## 三、视频：`@[video]`

```
@[video](https://cdn.example.com/video/sea.mp4 "海边的日落")
```

- 第一个参数是视频地址，必须是可直链播放的文件（推荐 `.mp4` / H.264，兼容性最好）。
- 第二个引号参数是标题，可省略；有标题时会显示在播放器下方。
- 渲染成卡片式播放器：播放/暂停、进度条、当前时长、倍速、静音、画中画、全屏（浏览器不支持画中画时该按钮不出现）。

```markdown
@[video](https://cdn.example.com/video/sea.mp4)

@[video](https://cdn.example.com/video/sea.mp4 "海边的日落")
```

## 四、音频：`@[audio]`

```
@[audio](https://cdn.example.com/audio/rain.mp3 "雨声 30 秒")
```

- 参数与视频一致：地址 + 可选标题。
- 渲染成带进度条的音频卡片，而不是浏览器默认的灰条。

## 五、附件：`@[file]`

```
@[file](https://cdn.example.com/files/report.pdf "季度报告.pdf" "2.3 MB")
```

- 三个参数依次是：文件地址、**显示名**、**体积文案**。
- 后两个都可以省，但省掉后显示的是地址里的原始文件名、且没有体积。
- 渲染成文件卡片（图标 + 文件名 + 体积 + 下载按钮），点整张卡片即可下载。

## 六、实况图：`@[live]`

实况图 = 一张静态封面 + 一段 1~3 秒的短视频。参数**顺序最容易记错**：括号里第一个是**视频**，引号里第一个是**封面图**，第二个引号才是说明。

```
@[live](https://cdn.example.com/live/sea.mp4 "https://cdn.example.com/live/sea.jpg" "海边日落")
```

| 位置 | 内容 | 是否必填 |
| --- | --- | --- |
| 括号内第一个参数 | 实况视频地址 | 必填 |
| 第一个引号参数 | 封面图地址 | 必填 |
| 第二个引号参数 | 说明文字 | 可选 |

- 封面和视频**缺任意一个**，短代码就不会渲染，而是原样显示源码。
- 交互：桌面悬停播放、手机按住播放，松手立即暂停复位；视频编码不支持或 404 时只留封面，不会出现破图。
- 视频建议 1~3 秒、30MB 以内；封面用与视频首帧一致的图最自然。

### 三种插入方式，任选其一

1. **安卓手机拍的实况照片**：直接选那张 `.jpg` 即可。它的视频内嵌在 JPEG 尾部，上传时后端会自动拆出视频，编辑器会直接插入正确的 `@[live]` 短代码，不用你手动拼。
2. **自己准备封面 + 视频**：点编辑器工具栏的「实况图」按钮，一次同时选一张图和一段短视频，自动上传并插入。
3. **手写**：按上面的格式自己写，地址从附件库复制。

> 注意：文章里用 `@[live]`，动态里不用。动态配图的存法是「图片::视频」，在发布器/编辑弹窗里点配图右下角的「实况」按钮设置（可本地上传短视频，也可以直接选附件库里已有的视频）。

## 七、普通图片：`![说明](地址)`

```markdown
![海边的日落](https://cdn.example.com/image/sea.jpg)
```

- 图片会自动加懒加载与异步解码，长文里几十张图也不会拖慢首屏。
- **把视频/音频地址写在图片位置也能用**：`![](a.mp4)` 会被自动识别成视频播放器，`![](a.mp3)` 识别成音频播放器——这是不熟悉短代码时最自然的写法，做了兜底。
- 图片支持点击放大（灯箱预览）。

## 八、行内表情：`[emoji:地址]`

```
今天的天气 [emoji:https://cdn.example.com/emoji/sun.png] 不错
```

- 用编辑器工具栏的表情按钮插入最省事，手写也可以。
- 地址同样只认 `http(s)://` 与 `/` 开头，且不能含空格、引号、尖括号。

## 九、@ 提及 与 # 话题 #

这两个不用学语法，**直接手打即可**，保存时后端会自动转成链接：

| 写法 | 效果 |
| --- | --- |
| `@昵称` | 转成指向作者主页的链接，并给对方发一条「被提及」通知 |
| `#话题名#` | 转成话题链接，话题不存在时自动创建，并计入本文的话题 |

补充说明：

- `@昵称` **只对「你已关注的人」生效**。没关注的人写了也只是普通文字，不会变链接、也不会通知——这是防止乱 @ 骚扰的设计。
- 话题名 1~32 个字符，不能含空格和 `#`；单篇内容最多关联 5 个话题。
- 已经写成链接形式的 `@[昵称](/author/12)`、`#[话题名](/topic/12)` 会被原样保留，重复保存不会二次转换。

## 十、标准 Markdown 支持范围

**支持**：

- 标题 `#` ~ `######`、粗体 `**`、斜体 `*`、删除线 `~~`、行内代码 `` ` ``
- 有序/无序列表、引用 `>`、分割线 `---`
- 表格（GFM 风格）、链接 `[文字](地址)`、裸链接自动识别
- 代码块（三个反引号 + 语言名），带语法高亮
- 单个换行即换行（不需要行尾加两个空格）

**不支持**：

- HTML 标签（会被转义成文字显示）
- 任务列表复选框 `- [ ]`（会显示成普通文字）
- 脚注、数学公式、自动生成目录

代码块高亮目前支持这些语言（写别名也可以）：

```
javascript / js / jsx / mjs / cjs / node, typescript / ts / tsx,
json / jsonc, bash / sh / zsh, shell / console, go / golang,
python / py, java / kotlin, php, rust / rs,
c / cpp / c++ / cc / h / hpp / csharp / cs,
sql / mysql, xml / html / vue / svg, css / scss / less,
yaml / yml, ini / toml / conf, markdown / md, diff / patch,
dockerfile / docker, nginx, plaintext / text / txt
```

不在列表里的语言会退化成不高亮的纯文本，不影响阅读。

## 十一、编辑器按钮对照

后台写作页（文章 / 独立页面 / 文档）的工具栏已经内置了对应按钮，点按钮选文件就会自动插入短代码，不必手写：

| 按钮（图标） | 插入的短代码 |
| --- | --- |
| 图片 | `![](地址)` |
| 视频 | `@[video](地址 "标题")` |
| 音频 | `@[audio](地址 "标题")` |
| 附件 | `@[file](地址 "文件名" "体积")` |
| 实况图 | `@[live](视频 "封面" "说明")` |
| 附件库（文件夹） | 从已上传的附件里挑，不重复上传 |
| 表情 | `[emoji:地址]` |

## 十二、常见问题

**1. 短代码原样显示成一串文字？**

按顺序排查：地址是不是 `http(s)://` 或 `/` 开头；地址里有没有空格或 `)`；`@[live]` 是不是把封面和视频写反了（括号里必须是视频）；结尾的 `)` 有没有漏；引号是不是英文双引号。

**2. 视频/音频显示成「加载失败」或空白？**

多半是站点没有放开该扩展名。后台「系统设置 → 存储 → 附件上传限制 → 允许的后缀」里加上 `mp4`、`mov`、`mp3` 等再保存即可（保存后立即生效）。其次检查文件是否真的能直链访问，以及编码是否是浏览器普遍支持的（视频优先 mp4/H.264，音频优先 mp3/AAC）。

**3. 在动态里写短代码没用？**

动态正文不渲染 Markdown，只处理表情。发实况图请用配图右下角的「实况」按钮；发动图请直接发图片或视频附件。

**4. 表格、代码块显示成一堆竖线或反引号？**

符号要用英文半角；代码块必须是**三个**反引号成对包裹，且开头那行只写语言名。

**5. @ 了对方但没变成链接、对方也没收到通知？**

说明你还没关注对方。@ 提及只对已关注的人生效。

## 十三、完整示例

````markdown
# 周末去了趟海边

风很大，但日落很好。顺手录了段实况：@[live](https://cdn.example.com/live/sea.mp4 "https://cdn.example.com/live/sea.jpg" "海边日落")

## 拍到的东西

| 内容 | 类型 | 时长 |
| --- | --- | --- |
| 日落 | 实况图 | 3 秒 |
| 海浪 | 视频 | 18 秒 |

@[video](https://cdn.example.com/video/wave.mp4 "海浪")

附件是当天的路线图：

@[file](https://cdn.example.com/files/route.pdf "海边路线.pdf" "1.2 MB")

同行的是 @小明，路线参考了 #海边徒步# 里的攻略 [emoji:https://cdn.example.com/emoji/sun.png]
````

按上面的写法渲染出来就是：标题、正文、一张可悬停播放的实况图、一个视频播放器、一张附件下载卡片，以及可点击的提及与话题。
