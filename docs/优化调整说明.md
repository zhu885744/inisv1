# inis CMS 系统优化调整说明

> 本次优化遵循「不新增业务功能，仅做优化调整」的原则，聚焦于**安全性、正确性、性能与代码质量**四个方面。所有修改均通过 `go build ./...` 编译验证，未引入编译错误。

## 二、安全修复（P0）

### 1. SQL 注入修复（`app/facade/mysql.go`）

**问题**：`Where`/`WhereIn`/`WhereNotIn`/`Not`/`Or`/`Like`/`ILike`/`Null`/`NotNull`/`Sum`/`Max`/`Min`/`Inc`/`Dec`/`UpdateColumn` 等方法的字段名、操作符、值直接通过 `fmt.Sprintf` 拼接进 SQL，存在 SQL 注入风险。

**修复**：
- 新增 `sanitizeColumn()` 字段名白名单校验（仅允许 `[a-zA-Z_][a-zA-Z0-9_]*` 及联表点号），非法字段名直接跳过该条件；
- 新增 `sanitizeOperator()` 操作符白名单校验（`=`/`!=`/`>`/`<`/`LIKE`/`IN` 等），非法操作符跳过；
- `ILike` 的 `LIKE '%value%'` 值拼接改为 GORM 参数占位 `?`；
- `Sum`/`Max`/`Min`/`Inc`/`Dec` 的聚合字段名增加校验，非法字段返回明确错误。

> **兼容性**：正常业务字段名（如 `id`/`title`/`uid`）均符合白名单，不影响现有功能；仅非法字段名（如含空格、分号、引号）被拦截。

### 2. 路径遍历修复（`config/app.go` + `app/facade/storage.go`）

**问题**：
- 静态文件读取 `public + path` 未做路径规范化，`../` 可读取任意文件；
- 本地存储删除 `os.Remove(path)` 未校验，`../../` 可删除任意文件；
- `strings.LastIndex` 返回 -1 时切片存在 panic 隐患。

**修复**：
- `notRoute` 拒绝包含 `..` 的请求路径，并对 `LastIndex` 越界做保护；
- `LocalStorageStruct.Delete` 使用 `filepath.Clean` 规范化后校验路径必须落在 `public` 目录内。

### 3. 密钥治理

| 文件 | 修复内容 |
|------|----------|
| `app/facade/crypt.go` | ① JWT 密钥文件写入权限 `0755 → 0600`；② 密钥生成由 `md5(uuid+时间戳)` 改为 `crypto/rand` 随机字节；③ 热更新日志不再打印 `jwt.key` 明文 |
| `app/facade/const.go` | 硬编码设备签名盐值 `Token` 改为 `DefaultToken`，新增 `GetToken()` 支持环境变量 `INIS_DEVICE_TOKEN` 覆盖 |
| `app/middleware/token.go` | 硬编码明文 Token `"0147."` 改为从配置 `app.token` 读取，比较改用 `subtle.ConstantTimeCompare` 恒定时间比较 |

## 三、正确性修复（P1）

### 4. 事务与并发治理

| 文件 | 修复内容 |
|------|----------|
| `app/api/controller/users.go` `ban` | 封禁时删除用户内容由「异步 goroutine」改为「同步执行 + 错误检查」，避免脱离事务失败无感知 |
| `app/model/users.go` `Destroy` | 注销清空关联数据由「裸 goroutine 并发删除」改为「同步删除 + 错误上抛」 |
| `app/model/users.go` `AfterSave` | 头像域名替换由「异步 goroutine 复用事务连接」改为「同步执行」，消除数据竞争与事务污染 |
| `app/model/exp.go` `Add` | 「经验值流水创建 + 用户经验自增」包入数据库事务，保证原子性 |

### 5. 错误处理补全

`app/model/users.go` `AfterSave` 中账号/邮箱/手机号唯一性校验，由 `exist, _ := ...Exist()` 忽略 error，改为显式检查 error 并记录日志，避免查询异常时绕过唯一性校验。

## 四、性能优化（P2）

### 6. 图片动态处理缓存（`config/app.go`）

**问题**：带 `?size=` 参数的图片每次请求都重新读盘 + 解码 + 裁剪 + 编码，CPU/IO 浪费严重。

**修复**：新增进程内 `sync.Map` 缓存，key 为 `path + size + mode`，命中直接返回处理结果；缓存上限 1024 条，超限整体清空，防止内存无限增长。

## 五、质量治理（P3）

### 7. 配置热更新 bug 修复（`main.go` + `config/app.go`）

**问题**：
- `watch()` 的 `OnConfigChange` 回调内递归调用 `watch()`，导致监听重复注册、goroutine 累积；
- `app.Run()` 内的 `select {}` 在回调中被调用时会永久阻塞。

**修复**：
- `app.Run()` 移除 `select {}`；
- `main.go` 改用 `signal.Notify` 阻塞主 goroutine，等待 `SIGINT`/`SIGTERM` 优雅退出；
- `watch()` 移除递归调用。

### 8. 调试输出清理

| 文件 | 清理内容 |
|------|----------|
| `app/api/controller/OAuth.go` | 移除 `qq`/`github` 方法中的 `fmt.Println` 调试输出 |
| `app/api/controller/test.go` | 移除 `returnUrl`/`notifyUrl`/上传接口中的 `fmt.Println` 调试输出 |

### 9. 注释修正

`app/api/controller/users.go` 两处注释「未了防止」修正为「是为了防止」。

## 七、行为变化与注意事项

1. **密钥文件权限**：`config/crypt.toml` 新生成时权限为 `0600`。已存在的旧文件权限不受影响，建议手动执行 `chmod 600 config/crypt.toml`。
2. **设备签名盐值**：默认值 `(unti.io)` 不变，通过环境变量 `INIS_DEVICE_TOKEN` 可覆盖。若部署环境设置了该变量，需确保与服务端约定一致。
3. **简单 Token 中间件**：`app/middleware/token.go` 的 `Token()` 中间件当前**未被路由引用**（死代码），本次修复后若未来启用，Token 从配置 `app.token` 读取，未配置时回退到原默认值。
4. **注销/封禁流程**：删除内容由异步改为同步，接口响应时间可能略微增加（数据量极大时），但换来了数据一致性保障。
5. **图片缓存**：动态裁剪结果缓存在进程内存中，重启后失效；原图更新后若 URL 的 `size` 参数不变，可能命中旧缓存（与原「每次实时裁剪」行为有差异）。如遇图片更新不生效，重启服务即可。
6. **优雅退出**：服务现在响应 `Ctrl+C`（SIGINT）或 `kill`（SIGTERM）信号进行优雅退出，替代原 `select {}` 阻塞方式。
