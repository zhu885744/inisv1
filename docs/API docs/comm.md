## Comm 接口文档

### 接口概述
公共控制器提供用户登录、注册、退出等核心认证功能。

### 状态码规范
| 状态码 | 含义 | 使用场景 |
| :--- | :--- | :--- |
| 200 | 请求成功 | 正常返回数据 |
| 201 | 创建成功 | 资源创建成功 |
| 400 | 请求错误 | 参数验证失败 |
| 401 | 未授权 | 未登录或权限不足 |
| 403 | 禁止访问 | 无操作权限 |
| 405 | 方法不允许 | 请求方法错误 |
| 412 | 前置条件失败 | Token为空 |
| 500 | 服务器错误 | 服务端异常 |

### 接口列表

#### 1. 用户登录
- **请求方式**: `POST`
- **请求路径**: `/api/comm/login`
- **参数**:
  | 参数名 | 类型 | 必填 | 说明 |
  | :--- | :--- | :--- | :--- |
  | account | string | 是 | 账号/邮箱/手机号 |
  | password | string | 是 | 密码 |
  | source | string | 否 | 登录来源，默认`default` |

- **响应示例**:
```json
{
  "code": 200,
  "msg": "登录成功！",
  "data": {
    "user": {...},
    "token": "xxx",
    "valid_time": 1296000
  }
}
```

> `valid_time` 为登录会话有效期（秒），由后端 `jwt.expire` 配置决定，默认 `15 * 24 * 60 * 60`（15 天）。前端应据此设置 cookie 与本地缓存的有效期。

#### 2. 用户注册
- **请求方式**: `POST`
- **请求路径**: `/api/comm/register`
- **参数**:
  | 参数名 | 类型 | 必填 | 说明 |
  | :--- | :--- | :--- | :--- |
  | social | string | 是 | 邮箱或手机号（用于接收验证码） |
  | code | string | 是 | 验证码 |
  | password | string | 是 | 密码 |
  | account | string | 否 | 用户名（未传则自动生成） |
  | nickname | string | 否 | 昵称（未传则自动生成） |

> **自动生成规则**：
> - **账号**：未传入时，自动生成从 `10000001` 开始递增的纯数字账号（8 位以内，上限 `99999999`）。系统会取现有账号中可转为数字的最大值 +1 作为下一个账号，保证首个账号为 `10000001` 并依次递增（如 `10000001`、`10000002` …）。
> - **昵称**：未传入时，自动生成为 `用户_` + 6 位随机数字（如 `用户_839204`）。

> **账号唯一性保障**：
> - `users.account` 字段已加**唯一索引**（`idx_account`），数据库层面杜绝重复。
> - 自动生成账号采用**冲突重试**机制：由于并发注册可能短暂取到相同的账号值，创建时若触发唯一索引冲突（MySQL 错误码 `1062`），会自动重新取下一个可用账号重试（最多 10 次），确保注册最终成功且不重复。
> - 注意：手动传入的 `account` 若与已有账号重复，同样会触发唯一索引冲突并返回错误，前端应提示用户更换账号。

- **响应示例**:
```json
{
  "code": 200,
  "msg": "注册成功！",
  "data": {
    "user": {...},
    "token": "xxx",
    "valid_time": 1296000
  }
}
```

> `valid_time` 为登录会话有效期（秒），同登录接口。

#### 3. 重置密码
- **请求方式**: `POST`
- **请求路径**: `/api/comm/reset-password`

**发送验证码（不传 code）**：
- **参数**:
  | 参数名 | 类型 | 必填 | 说明 |
  | :--- | :--- | :--- | :--- |
  | social | string | 是 | 邮箱或手机号 |

- **响应示例**:
```json
{
  "code": 201,
  "msg": "验证码发送至您的手机/邮箱：182****5257，请注意查收！",
  "data": null
}
```

**验证并重置密码（传入 code 和 password）**：
- **参数**:
  | 参数名 | 类型 | 必填 | 说明 |
  | :--- | :--- | :--- | :--- |
  | social | string | 是 | 邮箱或手机号 |
  | code | string | 是 | 验证码 |
  | password | string | 是 | 新密码 |

- **响应示例**:
```json
{
  "code": 200,
  "msg": "密码重置成功！",
  "data": null
}
```

**错误码说明**：
| 错误信息 | 说明 |
| :--- | :--- |
| 该手机号未注册！ | 提交的手机号未在系统中注册 |
| 该邮箱未注册！ | 提交的邮箱未在系统中注册 |
| 管理员未开启短信/邮箱服务 | 服务未配置 |
| 发送过于频繁，请60秒后再试！ | 短信发送间隔限制 |
| 今日发送验证码次数已达上限 | 每日发送次数超限（10次/日） |
| 验证码错误！ | 验证码不正确或已过期 |

**限流说明**：
| 类型 | 限制值 |
| :--- | :--- |
| 发送间隔 | 60秒（短信模式） |
| 每日次数 | 10次/日（短信模式） |

#### 4. 验证Token
- **请求方式**: `POST`
- **请求路径**: `/api/comm/check-token`
- **参数**:
  | 参数名 | 类型 | 必填 | 说明 |
  | :--- | :--- | :--- | :--- |
  | renew | bool | 否 | 是否刷新token |

- **响应示例**:
```json
{
  "code": 200,
  "msg": "合法的token！",
  "data": {
    "user": {...},
    "token": "xxx",
    "valid_time": 1296000
  }
}
```

> `valid_time` 为 token 剩余有效时间（秒）。

#### 5. 退出登录
- **请求方式**: `DELETE`
- **请求路径**: `/api/comm/logout`

### 特殊说明
- 登录支持密码密文解密（通过X-Gorgon、X-Khronos、X-Argus请求头）
- 注册需先发送验证码（不传code参数），再提交验证码完成注册
- 登录成功后会自动写入cookie存储token
- 登录成功后会增加用户经验值
- 登录/注册/校验接口均返回 `valid_time`（会话有效期秒数），默认 15 天（`jwt.expire` 配置决定），前端据此同步 cookie 与本地缓存有效期
