# 文章分组管理 接口文档

## 接口概述

`article-group` 控制器用于管理文章分组（栏目），支持分组的层级结构管理、CRUD 操作和树形结构展示。所有接口均支持软删除机制和缓存优化。

### 接口类型说明

| 接口类型 | 说明 |
| :--- | :--- |
| **基础接口** | 支持15个基础接口：one、all、rand、count、sum、min、max、column、remove、delete、clear、restore、save、create、update |
| **特殊接口** | tree - 获取树形结构 |

---

## 状态码规范

| 状态码 | 说明 | 使用场景 |
| :--- | :--- | :--- |
| **200** | 请求成功 | 获取数据成功、操作成功 |
| **201** | 创建成功 | 新增数据成功 |
| **204** | 无内容 | 查询无数据、无可操作数据 |
| **400** | 请求错误 | 参数校验失败、操作失败 |
| **401** | 未授权 | 用户未登录 |
| **403** | 无权限 | 无操作权限 |
| **405** | 方法不允许 | 请求方法错误或方法名错误 |
| **500** | 服务器错误 | 系统内部错误 |

## 接口列表

### 1. 获取单个分组 [one]

- **接口类型**: 基础接口 / 获取指定
- **请求方式**: `GET`
- **请求地址**: `/api/article-group/one`
- **说明**: 根据条件获取单个文章分组

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | int | 否 | 分组ID |
| `field` | string | 否 | 返回字段，逗号分隔 |
| `where` | json | 否 | 条件查询 |
| `like` | json | 否 | 模糊查询 |
| `withTrashed` | bool | 否 | 是否包含已删除数据 |
| `onlyTrashed` | bool | 否 | 是否只查询已删除数据 |

**成功响应** (200):

```json
{
    "code": 200,
    "msg": "数据请求成功！",
    "data": {
        "id": 1,
        "pid": 0,
        "name": "技术文章",
        "key": "tech",
        "description": "技术相关文章",
        "create_time": 1699900000
    }
}
```

## 特殊说明

### 1. 树形结构
- `tree` 接口返回嵌套的树形结构，适用于层级分类展示
- 支持递归查询子分组

### 2. 字段处理
- `json` 和数组类型字段会自动序列化

### 3. 缓存策略
- 所有查询接口均支持缓存
- 数据修改后会自动清除相关缓存
