## Mellow 主题（Vue3 + Vite）安全与性能审查

代码基础很好：路由全懒加载（120 处 `import()`）、手写 manualChunks（highlight/markdown 拆分，最大 chunk 128K）、GET 并发去重、`html:false` 的 markdown-it、`renderEmoji` 先转义后替换、`thumbUrl` 按显示尺寸取图、socket 退避重连且可见性感知、通知轮询已处理 `document.hidden`。所以只修真实缺口：

### 安全
- **新增 `src/utils/url.js`（`safeUrl` / `isSafeUrl` / `isInternalPath` / `protocolOf`）**：Vue 的 `:href` 不拦截 `javascript:`。个人网站（`users.json.website.url`）是用户可写字段，资料页只在前端表单校验 `^https?://`，直接调接口即可绕过 → 任何访客（含管理员）点开该主页的「个人网站」胶囊即在本站域执行脚本，token 在可读 cookie 里 = 账号接管。同一问题存在于友链、后台公告 `url`、自定义菜单、页脚备案链接、侧栏「更多」入口、浮动按钮 `window.open`。
- **`src/utils/html.js` 的 `sanitizeHtml` 协议判断改为白名单**：原实现 `value.startsWith('javascript:')`，可被 `java\tscript:` / 换行 / 大小写变体绕过（浏览器解析 URL 时会忽略 tab 与换行）。新实现先剥控制字符与空白，再按「有没有协议 + 协议是否在 http/https/mailto/tel 白名单」判定；URL 类属性（href/src/xlink:href/action/poster/... 含 srcset 候选列表）全覆盖；图片类属性额外放行 `data:image/(png|jpe?g|gif|webp|avif|bmp)` 但**排除 svg**。`hasUnsafeScheme` 已导出，可直接跑用例。
- **`src/utils/cookie.js` 补 SameSite/Secure**：按「是否同站」分流 —— 同源或同一注册域子域用 `SameSite=Lax`（挡住跨站携带，XHR 不受影响），真正跨站部署用 `None; Secure`（浏览器只接受这一种），http 页面不加 Secure。注意后台 `INIS_ADMIN_TOKEN` 由后端下发（HttpOnly），不受影响。

### 性能
- `ArticleCard.vue` 封面框只有 160×108 却拉原图，改 `thumbUrl(cover, 320)`（图床不支持时原样返回）。
- `room/Index.vue` 的 60s `loadInfo` 轮询加 `document.hidden` 判断。
- `.gitignore` 补 `.env.local` / `.env.*.local`：`.env` 已被 git 跟踪且是 VITE_AES_KEY 的存放位置，这类变量会被打进产物，只能当混淆用。
